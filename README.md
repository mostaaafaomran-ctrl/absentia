# Track absences before the university limit

Absence tracker for university students: per-course counters and a warning before you hit the limit. Arabic + English.

**Live:** https://mostaaafaomran-ctrl.github.io/absentia/

- Runs fully in the browser, nothing uploaded, no signup
- Plain HTML/CSS/JS, no build step, no dependencies
- Arabic and English

## Run locally
Open `index.html` in a browser.

## Logic tests
`core.js` works in Node: `node -e "console.log(Object.keys(require('./core.js')))"`
